# FitVault

**FitVault** is a fitness-focused product discovery and price comparison platform that helps users find the **best deals on shoes and apparel** across multiple retailers — fast, clean, and reliable.

Built with scalability and data quality in mind, FitVault aggregates products, normalizes pricing, and highlights the lowest available offers in real time.

---

## Features

- **Product Discovery**
  - Browse fitness shoes and apparel
  - Brand, category, and search-based navigation

- **Price Comparison**
  - Compare prices across retailers
  - Automatically highlights the lowest price
  - Shows “Last updated” timestamps for transparency

- **Smart Data Layer**
  - Canonical product categories
  - Freshness checks on prices
  - Deduplication and normalization logic

- **Performance First**
  - Pagination for large catalogs
  - Lazy-loaded images
  - Optimized API responses
